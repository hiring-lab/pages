Indeed Labor Market Tightness Index — blog visuals

Two standalone interactive charts built from the May 2026 Indeed Labor Market Tightness Index. Each is a single self-contained HTML file, sized to be embedded in a post with an <iframe>.

Interactive map →

Choropleth of the index by metro and micropolitan area (CBSA). Hover an area for its name and index value; the state dropdown zooms the map, and the circular-arrow button beside it resets to the national view (disabled until a state is picked). There is no table view — the map is the whole page — but Download CSV gives the full set of values.

Height 890 at a 779px column — the content measures 881px at every state in the dropdown, so one fixed height works. (Measured at other widths: use 825 at 680px, 960 at 1000px.)

Interactive ranking →

Ranked bars against the national median. Switch between tightest markets, slackest markets, and a single state; the slider sets how many areas appear. The Table (all markets) view lists all 828 publishable areas — searchable and sortable by rank, name or index — and is deliberately not scoped by the chart controls, so a reader can always look up their own area. Those four chart-only filters hide themselves in table view rather than sitting there inert.

Height 1035 — the content is a constant 1027px at every slider position, mode and size filter (the plot area is fixed and the bars thin out instead of the chart growing). The table view is tuned to the same 1027px, so switching views never moves the frame.

Sizing. Both pages are responsive, so a percentage width also works if the embed is set to be responsive. Heights above are measured at the 779px article column width in Noto Sans; a narrower frame makes the map taller, so re-check if you change the width. Neither page ever changes its own height in response to a control, which is what lets a single fixed height work.

Auto-height (optional). Each page posts its height to the parent as {type:"hiringlab-embed-height", id, height}. Nothing listens by default; add a listener in the post only if you want the frame to shrink-wrap.

Data download. Both pages have a Download CSV button that writes all 828 publishable areas — rank, cbsa_code, cbsa_title, states, tightness_index, large_market — as indeed-labor-market-tightness-index-may-2026.csv. It is always the full set, never the current view, and it carries a UTF-8 BOM so Excel reads “Española, NM” correctly. Raw posting and seeker counts are not in the page payload, so they cannot be exported. One caveat: the download is generated in-page as a blob, so if the embed is given a sandbox attribute it must include allow-downloads. With no sandbox attribute (the default, and what the snippets above use) it just works.

Theme. Add ?theme=dark to force the dark palette or ?theme=auto to follow the reader's OS. Default is light, which is what a light article wants.

PNG export. The camera button in each chart's toolbar is not plotly's default — that one captures the plot area alone, so the file came out with no title, no source line and no logo. It is replaced with one that composes the export the way aurora_save() composes a PNG: title and subtitle above, source line bottom-left, Indeed logo bottom-right, at the 1559×922 that ggsave_aurora_blog(size = "body") writes. Filenames follow the current view (indeed-tightness-index-tightest-15.png, indeed-tightness-index-map-texas.png). Exports are always the light palette — the logo raster is brand blue and needs a light ground, and hlplot ships no white variant — so a reader in dark mode still gets a light PNG.

Naming. Both pages name the measure in full — Indeed Labor Market Tightness Index — in the page title, the on-chart subtitle, the source line and the CSV filename, with the short form “tightness index” used only inside tooltips and column headers where the full name would crowd the layout.

Styling. Both pages carry the Aurora design tokens ported from hlplot::theme_aurora() — Noto Sans, Gray 100 #2D2D2D text, palette_aurora hues, no ticks, no axis titles — and the Indeed logo bottom-right, inlined from hlplot at build time the way aurora_save() stamps it on a PNG.

Source: Indeed Hiring Lab. Rebuild with Rscript final-visuals.R.
